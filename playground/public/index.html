GitHub Key 配置与 Codespaces 云端真机管理

1. 配置 GitHub Personal Access Token

输入你的 GitHub Token（仅保存在当前浏览器 localStorage，直接与 api.github.com 通信），即可开启：

  • 在网页内直接为任意开源项目 创建、启动、连接端口预览和销毁 GitHub Codespaces 云端容器
  • 突破匿名 GitHub API 60 次/小时限制，实时拉取任意仓库的完整 README.md 与元数据
↗ 一键前往 GitHub 生成带 codespace + repo 权限的 Token
